# Gateway Arch StoryMap

Interactive St. Louis counter-mapping presentation.

## Publish on GitHub Pages

1. Create a public GitHub repository named `gateway-arch-storymap`.
2. Upload the **contents** of this ZIP (`index.html` and `README.md`) to the repository root (not the ZIP itself).
3. Commit the files to the `main` branch.
4. Go to Settings > Pages > Build and deployment > Deploy from a branch; choose `main` and `/ (root)` and save.
5. Visit `https://YOUR-USERNAME.github.io/gateway-arch-storymap/` after deployment.

The HTML is the latest approved source-enhanced version, unchanged in its chapter text and embedded images. Background map tiles and some images require internet access.
